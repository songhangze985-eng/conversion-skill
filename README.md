# 转换skill 🎭✨

> 把"读了好几遍还是不懂"的专业知识,变成生动好懂的二次元故事 🌈

## ✨ 它能做什么

把"硬核知识"翻译成"有趣故事",但**不失真** 🎯

| 输入 | 输出 |
|---|---|
| 贝叶斯定理公式 | 异世界侦探社的推理故事 🕵️‍♀️ |
| 快速排序算法 | 校园运动会选拔赛 ⚡ |
| Raft 共识协议 | 议会投票表决 🏛️ |
| 抗体免疫机制 | 城门守卫识别通缉犯 🛡️ |

**核心特点:**
- 🔍 **四步可追溯**:理解 → 提炼 → 意象映射 → 转换,每步独立成节,不跳步
- 🎨 **风格丰富**:角色化 / 场景化 / 对话化 / 拟人化 / 伏笔反转,至少满足 3 项
- ✅ **知识保真**:故事后附"知识点校验",确保趣味不牺牲正确性
- 🎚️ **强度可调**:轻度 / 标准 / 重度三档,适配不同场合
- 📥 **格式兼容**:纯文本、Markdown、LaTeX 公式均可

## 🧭 四步转换流水线

skill 严格按以下顺序输出,**每步独立成节**,可追溯、可纠错 🔍

### 第 1 步 · 理解 (Understand) 💡

用自己的话复述原文含义,指出最难懂、最易误解的地方。**把"可能没读懂"的风险前置暴露**,而不是把误解一路带到故事里。

### 第 2 步 · 提炼 (Extract) 📋

抽取所有关键概念、变量、关系、约束条件,结构化呈现。这是后续映射的"事实清单"——清单不准,故事再精彩也会失真 ⚠️

### 第 3 步 · 意象映射 (Map) 🔮

为每个关键概念找一个"形神兼备"的故事元素映射,写出映射关系表。用"心智理论"换位思考:

- ① **形似**:表面像不像?🤔
- ② **神似**:内在机制能否对应?🧠

两层都过关才用。比如"概率更新"→"侦探改写嫌疑人名单",表面是数字变化,内在是"依据新证据修正判断",两层都成立 ✅

### 第 4 步 · 转换 (Convert) 📖

以二次元 / 故事风格输出完整生动的表达。要有头有尾、自洽完整,不是片段。综合运用至少 3 项风格要素 🎨

## 🎨 风格要素

输出故事化表达时,从以下 5 项中**至少满足 3 项** 🎯

| # | 要素 | 说明 | 示例 |
|---|---|---|---|
| 1 | 🧑‍🎤 **角色化** | 概念实体化为有名字、性格的角色 | "贝叶斯酱""快排君" |
| 2 | 🏫 **场景化** | 构建具象故事场景 | 校园 / 异世界 / 咖啡馆 / 实验室 |
| 3 | 💬 **对话化** | 用角色对话推动解释 | 「关键就在分母……」 |
| 4 | 🤖 **拟人化** | 抽象机制拟人化为可观察行为 | 概率更新→侦探改写名单 |
| 5 | 🪄 **伏笔 / 反转** | 剧情小反转增强记忆点 | 「原来脚印可能是别人留的……」 |

> 深入理解每项要素的边界与范例,见 [`references/style-elements.md`](references/style-elements.md) 📚

## 🎚️ 风格强度可调

三档风格适配不同场合,**知识准确性始终不打折** 📐

| 档位 | 别名 | 风格特征 | 适用场合 |
|---|---|---|---|
| 📝 轻度 | — | 克制比喻,接近科普文风,角色化弱 | 严肃场合 / 技术评审 |
| 📖 标准 | — *(默认)* | 完整角色与场景,二次元轻小说风 | 日常科普 / 学习笔记 |
| 🌌 重度 | 中二 | 夸张角色设定、专有名词、戏剧化对白 | 娱乐场景 / 社区分享 |

切换方式:在输入中说一句「用**重度**风格」即可。切换后第 4 步按对应风格呈现;第 1-3 步分析保持客观,不受风格影响 🎯

## 🛠️ 脚本工具

三个脚本仅依赖 Python 3 标准库,**无第三方依赖**,Windows 兼容 ✅

### 1️⃣ `validate_input.py` — 输入校验 🔍

检测空输入、闲聊文本、LaTeX 公式,输出结构化 JSON。

```bash
python scripts/validate_input.py "贝叶斯定理 $P(A|B)=\frac{P(B|A)P(A)}{P(B)}$"
```

输出示例:
```json
{"is_empty": false, "is_chitchat": false, "has_formula": true, "recommend_action": "explain_formula_first"}
```

`recommend_action` 取值:`proceed`(正常执行)/ `explain_formula_first`(先解释公式)/ `ask_for_input`(提示用户提供文本)

### 2️⃣ `generate_template.py` — 模板生成 ⚡

根据知识点名称与风格强度,生成四步输出骨架。

```bash
python scripts/generate_template.py --topic "快速排序" --style standard
python scripts/generate_template.py --topic "区块链" --style heavy --with-formula
```

`--style` 可选:`light` / `standard` *(默认)* / `heavy`

### 3️⃣ `check_output.py` — 输出校验 ✅

检查转换结果是否含四步标题、知识点校验小节,粗略统计风格要素满足数。

```bash
python scripts/check_output.py result.md
python scripts/check_output.py result.md --json   # 输出 JSON 格式
```

输出校验报告,标注四步是否齐全、知识点校验是否存在、风格要素是否 ≥3,给出 PASS / FAIL 结论 🎯

## 🌟 完整示例

**Input:** 贝叶斯定理 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$

**Output(节选第 4 步):**

> 🌧️ 异世界侦探社,雨夜。
>
> 「贝叶斯酱,又有案子了。」前辈把一份卷宗拍在桌上。
>
> 名叫贝叶斯的少女侦探揉了揉眼睛。她对嫌疑人 X 的初始怀疑度,只有 **三成**——这就是她的"先验"。
>
> 「不过……」她蹲下身,盯着泥泞里的脚印,「这是 X 那双限量版靴子留下的纹路。」
>
> 这就是证据 **B**。假如 X 真是凶手,留下这种脚印的可能性高达九成(似然 $P(B|A)=0.9$);可这双靴子在全市卖了不少,别人也可能留下同样脚印——所以脚印 B 总体出现的概率 $P(B)$ 并不低。
>
> 「关键就在分母。」她咬着笔杆喃喃自语,「我要把'别人也会留脚印'这部分干扰扣掉……」
>
> $$\text{新怀疑度} = \frac{\text{脚印在凶手身上的常见度} \times \text{原本的怀疑度}}{\text{脚印总体的常见度}}$$
>
> 笔尖一顿,数字跳出:**六成八**。
>
> 「嫌疑人 X 的嫌疑,从三成升到了六成八。这就是'后验'——看到证据之后,更新过的判断。」 🕵️‍♀️✨

**知识点校验:** 贝叶斯定理 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$,表示观测到 B 后 A 的后验概率由先验 $P(A)$ 与似然 $P(B|A)$ 的乘积除以 B 的边缘概率 $P(B)$(归一化项)得到,要求 $P(B)>0$ 且所有概率在 $[0,1]$ 区间 ✅

> 本段满足:角色化 ✅ 场景化 ✅ 对话化 ✅ 拟人化 ✅(4 项 ≥ 3 项)🎉

更多领域示例见 [`references/domain-examples.md`](references/domain-examples.md) 📚

## ❓ FAQ

<details>
<summary><b>Q1:故事会不会扭曲原意?</b> 🤔</summary>

不会。skill 强制在故事后附"知识点校验"小节,用 1-3 句话准确复述原文核心,确保读者能回溯到严谨定义。趣味性与正确性冲突时,**正确性优先** 🎯

</details>

<details>
<summary><b>Q2:输入含 LaTeX 公式怎么办?</b> 🧮</summary>

skill 会先用自然语言解释公式含义,再进入四步流程。这样不熟悉公式的读者也能跟上后续故事 📖

</details>

<details>
<summary><b>Q3:能处理哪些领域的知识?</b> 🌐</summary>

任意"专业知识"领域:数学 / 算法 / 分布式系统 / 数据库 / 医学机理 / 物理概念 / 经济模型 / 安全协议等。对纯主观话题(如"今天心情")会友善提示用户改用其他方式 💡

</details>

<details>
<summary><b>Q4:脚本必须运行吗?</b> 🛠️</summary>

不必须。skill 核心是提示词驱动的推理,脚本是**辅助工具**——用于校验输入、生成模板、检查输出完整性。可在需要时调用,也可完全手动操作 🤝

</details>

<details>
<summary><b>Q5:如何指定风格强度?</b> 🎚️</summary>

在输入中直接说「用轻度 / 标准 / 重度 / 中二风格」即可,未指定则默认标准 📖

</details>
