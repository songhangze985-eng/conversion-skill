# 转换skill

把"读了好几遍还是不懂"的专业知识,变成生动好懂的二次元故事。

将晦涩的专业知识(算法、公式、系统架构、底层机理等)通过四步流水线转化为二次元 / 故事风格的表达,让抽象概念具象化、易理解、易记忆。核心是一条四步转换流水线:理解 → 提炼 → 意象映射 → 转换,每步独立成节、可追溯,让读者既能读到趣味性的故事化版本,也能准确回溯到原始的严谨定义。

## 它能做什么

把硬核知识翻译成有趣故事,但不失真。

| 输入 | 输出 |
|---|---|
| 贝叶斯定理公式 | 异世界侦探社的推理故事 |
| 快速排序算法 | 校园运动会选拔赛 |
| Raft 共识协议 | 议会投票表决 |
| 抗体免疫机制 | 城门守卫识别通缉犯 |

核心能力:

| 能力 | 说明 |
|---|---|
| 四步可追溯 | 理解 → 提炼 → 意象映射 → 转换,每步独立成节,不跳步 |
| 长文章生成 | 6维度构思 + 段落规范 + 去AI味修订,适配简约/适中/专业三层字数 |
| 输出聚焦 | 分析过程折叠,文章突出标注,末尾集中展示完整文章 |
| 风格丰富 | 角色化/场景化/对话化/拟人化/伏笔反转,至少满足3项 |
| 知识保真 | 故事后附"知识点校验",确保趣味不牺牲正确性 |
| 强度可调 | 轻度/标准/重度三档,适配不同场合 |
| 角色配置 | 自定义模式(5必填字段)与随机生成模式,按输出层次分层触发 |
| 格式兼容 | 纯文本、Markdown、LaTeX 公式均可 |

## 快速开始

### 安装

将本 skill 包放入 TRAE / Claude Code 的 skills 目录:

```
<skills根目录>/
└── 转换skill/
    ├── SKILL.md
    ├── scripts/
    ├── references/
    └── assets/
```

### 触发 skill

在对话中直接表达需求即可触发,不需要记住"转换"这个词:

- "贝叶斯定理这个公式我看不懂,能不能用比喻讲讲?"
- "Raft 共识算法太抽象了,希望用故事讲清楚"
- "把这个概念讲得生动一点,二次元风格"
- "转换一下这段分布式锁的原理"

即使用户没明说"转换",只要表达"看不懂 / 太抽象 / 想用比喻类比 / 希望讲得生动",skill 都会被触发。

### 指定风格强度(可选)

在输入中加一句即可切换档位:

- 轻度 — 克制比喻,接近科普文风
- 标准 — 完整角色场景,二次元轻小说风(默认)
- 重度/中二 — 夸张戏剧化,专有名词拉满

### 指定输出层次(可选)

在输入中加一句即可切换层次:

- 简约 — ≤1500字,适合入门科普与低龄读者
- 适中 — 3000-6000字,适合日常学习与笔记整理(默认)
- 专业 — 10000-15000字,适合技术评审与深度学习

## 四步转换流水线

skill 严格按以下顺序输出,每步独立成节,可追溯、可纠错。

### 第 1 步 · 理解 (Understand)

用自己的话复述原文含义,指出最难懂、最易误解的地方。把"可能没读懂"的风险前置暴露,而不是把误解一路带到故事里。

### 第 2 步 · 提炼 (Extract)

抽取所有关键概念、变量、关系、约束条件,结构化呈现。这是后续映射的"事实清单"——清单不准,故事再精彩也会失真。

### 第 3 步 · 意象映射 (Map)

为每个关键概念找一个"形神兼备"的故事元素映射,写出映射关系表。用"心智理论"换位思考:

- 形似:表面像不像?
- 神似:内在机制能否对应?

两层都过关才用。比如"概率更新"→"侦探改写嫌疑人名单",表面是数字变化,内在是"依据新证据修正判断",两层都成立。

### 第 4 步 · 转换 (Convert)

按长文章生成引擎规范输出完整长文:动笔前完成6维度构思,遵循 web-serial-natural 段落规范,初稿后执行去AI味三步修订。综合运用至少3项风格要素。文章须有头有尾、自洽完整。二次元风格与通俗易懂为硬性约束,不得因篇幅增加而转为学术腔。字数严格对应输出层次要求。

## 长文章生成引擎

第4步转换不只是"写个故事",而是按长文章生成引擎规范输出完整长文,适配三层输出层次的字数要求。借鉴自媒体创作与长篇小说控盘经验,在动笔前完成6维度构思,遵循段落规范,并在初稿后执行去AI味修订。

### 6维度内容构思

动笔前完成以下6维度构思(内部思考,不展示给用户):

1. 核心记忆点:读者读完只记住的一句话
2. 情感曲线:开头张力 → 中段紧张释放交替 → 高潮 → 结尾余韵
3. 论证多样性:故事/类比/对话/反问交替,不单一
4. 金句:2-3个可独立传播的记忆锚点,自然嵌入
5. 视角切换:故事段第一人称,分析段第三人称,建议段第二人称
6. 钩子闭环:开头埋钩子,结尾回收,形成闭环

### 段落与节奏规范

遵循 web-serial-natural 段落模式:叙事段落2-4句为一段,单句段落仅用于强调/揭示/震惊/切换/钩子。长文中每800-1000字设置一个小高潮或转折点,避免通篇高亢或通篇平淡。

### 去AI味三步修订

文章初稿完成后执行:

1. 去套话:删除"值得注意的是""综上所述"等AI模板句式
2. 去过度术语:压低普通读者难懂的术语,用二次元场景替代抽象概念
3. 恢复语感:恢复二次元语感(角色口头禅/语气词/轻小说句式),确保通俗易懂

深入理解各维度的示例与清单,见 [`references/long-article-engine.md`](references/long-article-engine.md)。

## 输出聚焦

生成内容时,对输出分层呈现,让用户第一眼看到的就是文章本体,而非四步分析过程。

### 三层呈现规则

1. 折叠分析区:第1-3步(理解/提炼/意象映射)与知识点校验,默认折叠,用 `<details>` 标签包裹。
2. 突出文章区:第4步文章用醒目标题标注,前后用分隔线隔开,标题下方标注元信息(输出层次/风格/字数)。
3. 末尾完整文章展示:独立成节,集中展示完整文章全文,方便复制。简约模式下文章正文区与末尾展示区可合并。

输出结构:[折叠的分析区] → [突出的文章区] → [末尾完整文章展示]。使用 [`assets/templates/article-output-template.md`](assets/templates/article-output-template.md) 模板。

## 风格要素

输出故事化表达时,从以下5项中至少满足3项。

| # | 要素 | 说明 | 示例 |
|---|---|---|---|
| 1 | 角色化 | 概念实体化为有名字、性格的角色 | "贝叶斯酱""快排君" |
| 2 | 场景化 | 构建具象故事场景 | 校园/异世界/咖啡馆/实验室 |
| 3 | 对话化 | 用角色对话推动解释 | 「关键就在分母……」 |
| 4 | 拟人化 | 抽象机制拟人化为可观察行为 | 概率更新→侦探改写名单 |
| 5 | 伏笔/反转 | 剧情小反转增强记忆点(操作类/公式类不适用) | 「原来脚印可能是别人留的……」 |

深入理解每项要素的边界与范例,见 [`references/style-elements.md`](references/style-elements.md)。

## 风格强度可调

三档风格适配不同场合,知识准确性始终不打折。

| 档位 | 别名 | 风格特征 | 适用场合 |
|---|---|---|---|
| 轻度 | — | 克制比喻,接近科普文风,角色化弱 | 严肃场合/技术评审 |
| 标准 | —(默认) | 完整角色与场景,二次元轻小说风 | 日常科普/学习笔记 |
| 重度 | 中二 | 夸张角色设定、专有名词、戏剧化对白 | 娱乐场景/社区分享 |

切换方式:在输入中说一句「用重度风格」即可。切换后第4步按对应风格呈现;第1-3步分析保持客观,不受风格影响。

## 输出层次

除风格强度外,另设"输出层次"维度,控制输出的深度与篇幅。两个维度正交独立:风格强度管"怎么讲",输出层次管"讲多深讲多少"。

| 层次 | 触发条件 | 输出字数 | 文章结构 | 适用场景 |
|---|---|---|---|---|
| 简约 | 低龄化文本/简单概念/短文本 | ≤1500字 | 单场景+单对话+金句 | 入门科普、低龄读者 |
| 适中(默认) | 常规专业知识 | 3000-6000字 | 起承转合+2-3金句+钩子闭环 | 日常学习、笔记整理 |
| 专业 | 高专业度+大信息量+复杂逻辑 | 10000-15000字 | 多线叙事+章节分段+深度推导+伏笔回收 | 技术评审、深度学习 |

切换方式:在输入中说一句「用简约/适中/专业层次」即可。

## 角色配置

第4步转换用到角色时,支持两种角色来源:自定义模式与随机生成模式。两种模式按输出层次分层触发。

### 自定义模式

由用户指定角色详情。触发条件:适中模式的长文本或专业模式。

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 角色数量 | 必填 | 整数,建议1-5个 |
| 姓名 | 必填 | 每个角色的名字 |
| 性别 | 必填 | 男/女/其他 |
| 能力素养 | 必填 | 从低到高,如"初级/中级/高级"或1-10分 |
| 专业领域 | 必填 | 角色擅长的领域,需与待转换知识相关 |
| 基础数值 | 可选 | 身高、体重等与知识无强相关性的属性,可不填 |

### 随机生成模式

由skill自动构造角色。触发条件:简约模式,或自定义模式的必填字段缺失时回退。按领域识别→原型筛选→随机抽取→命名生成→字段补全的流程执行。

用户显式声明"自定义角色"或"随机角色"时,优先于层次判别。详见 [`assets/templates/character-archetypes.md`](assets/templates/character-archetypes.md)。

| 输入类型 | 处理方式 |
|---|---|
| 纯文本 | 直接进入四步流程 |
| Markdown | 按语义解析后进入四步流程 |
| 含公式文本(LaTeX) | 先用自然语言解释公式,再进入四步流程 |

## 脚本工具

三个脚本仅依赖 Python 3 标准库,无第三方依赖,Windows 兼容。

### validate_input.py — 输入校验

检测空输入、闲聊文本、LaTeX 公式,推荐输出层次,输出结构化 JSON。

```bash
python scripts/validate_input.py "贝叶斯定理 $P(A|B)=\frac{P(B|A)P(A)}{P(B)}$"
```

输出示例:
```json
{"is_empty": false, "is_chitchat": false, "has_formula": true, "has_mixed_content": false, "recommend_level": "适中", "recommend_action": "explain_formula_first"}
```

### generate_template.py — 模板生成

根据知识点名称、风格强度与输出层次,生成四步输出骨架。

```bash
python scripts/generate_template.py --topic "快速排序" --style standard
python scripts/generate_template.py --topic "区块链" --style heavy --level professional
python scripts/generate_template.py --topic "递归" --level simple
```

`--style` 可选:`light` / `standard`(默认) / `heavy`
`--level` 可选:`simple` / `moderate`(默认) / `professional`

### check_output.py — 输出校验

检查转换结果是否含四步标题、知识点校验小节,统计风格要素满足数与字数,校验层次范围。

```bash
python scripts/check_output.py result.md
python scripts/check_output.py result.md --json   # 输出 JSON 格式
```

输出校验报告,标注四步是否齐全、知识点校验是否存在、风格要素是否≥3、字数与层次达标情况,给出 PASS / FAIL 结论。

## 完整示例

**Input:** 贝叶斯定理 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$

**Output(节选第4步):**

> 异世界侦探社,雨夜。
>
> 「贝叶斯酱,又有案子了。」前辈把一份卷宗拍在桌上。
>
> 名叫贝叶斯的少女侦探揉了揉眼睛。她对嫌疑人 X 的初始怀疑度,只有 **三成**——这就是她的"先验"。
>
> 「不过……」她蹲下身,盯着泥泞里的脚印,「这是 X 那双限量版靴子留下的纹路。」
>
> 这就是证据 **B**。假如 X 真是凶手,留下这种脚印的可能性高达九成(似然 $P(B|A)=0.9$);可这双靴子在全市卖了不少,别人也可能留下同样脚印——所以脚印 B 总体出现的概率 $P(B)$ 并不低。
>
> 「关键就在分母。」她咬着笔杆喃喃自语,「我要把'别人也会留脚印'这部分干扰扣掉……」
>
> $$\text{新怀疑度} = \frac{\text{脚印在凶手身上的常见度} \times \text{原本的怀疑度}}{\text{脚印总体的常见度}}$$
>
> 笔尖一顿,数字跳出:**六成八**。
>
> 「嫌疑人 X 的嫌疑,从三成升到了六成八。这就是'后验'——看到证据之后,更新过的判断。」

**知识点校验:** 贝叶斯定理 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$,表示观测到 B 后 A 的后验概率由先验 $P(A)$ 与似然 $P(B|A)$ 的乘积除以 B 的边缘概率 $P(B)$(归一化项)得到,要求 $P(B)>0$ 且所有概率在 $[0,1]$ 区间。

本段满足:角色化、场景化、对话化、拟人化(4项 ≥ 3项)。

更多领域示例见 [`references/domain-examples.md`](references/domain-examples.md)。

<details>
<summary><b>Q1:故事会不会扭曲原意?</b></summary>

不会。skill 强制在故事后附"知识点校验"小节,用1-3句话准确复述原文核心,确保读者能回溯到严谨定义。趣味性与正确性冲突时,正确性优先。

</details>

<details>
<summary><b>Q2:输入含 LaTeX 公式怎么办?</b></summary>

skill 会先用自然语言解释公式含义,再进入四步流程。这样不熟悉公式的读者也能跟上后续故事。

</details>

<details>
<summary><b>Q3:能处理哪些领域的知识?</b></summary>

任意"专业知识"领域:数学、算法、分布式系统、数据库、医学机理、物理概念、经济模型、安全协议等。对纯主观话题(如"今天心情")会友善提示用户改用其他方式。

</details>

<details>
<summary><b>Q4:脚本必须运行吗?</b></summary>

不必须。skill 核心是提示词驱动的推理,脚本是辅助工具——用于校验输入、生成模板、检查输出完整性。可在需要时调用,也可完全手动操作。

</details>

<details>
<summary><b>Q5:如何指定风格强度与输出层次?</b></summary>

风格强度:在输入中说「用轻度/标准/重度/中二风格」,未指定则默认标准。
输出层次:在输入中说「用简约/适中/专业层次」,未指定则默认适中。
两者正交独立,可自由组合。

</details>

<details>
<summary><b>Q6:如何自定义角色?</b></summary>

在适中模式长文本或专业模式下,提供角色字段(数量/姓名/性别/能力素养/专业领域,基础数值可选)触发自定义模式。简约模式自动随机生成。必填字段缺失时回退随机生成。详见"角色配置"章节。

</details>
