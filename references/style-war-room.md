# 项目战情室表达（war-room）

当所讲机制涉及**「多节点协同、并发调度、网络通信协议、拥塞控制或容灾切换」**时使用。战情室不是霸道总裁发号施令的秀场，而是**多个岗位在信息受限、时间紧迫的条件下，靠严密规矩配合运转的现场**。

## 叙事四步

1. **亮出看板与危机**：一句话交代系统当前要守住的目标，以及各个席位各自只能看到什么局部信息（还原真实的分布式/局部视野）。
2. **信令流转**：把抽象的数据包、锁、令牌或选票，写成席位之间传递的确认单、号牌或倒计时。
3. **触发熔断与防线（约束生效）**：写出当延迟飙升、两边的请求撞车、或某个席位突然失联时，哪条预设铁律当场生效，拦住了混乱扩散。
4. **状态落定**：用看板上最终一致的状态收尾，并一句话总结这套协同机制靠什么守住底线。

## 禁区

- 严禁把需要「多数派投票」或「去中心化对表」的机制偷懒写成「总指挥一拍桌子全员执行」。
