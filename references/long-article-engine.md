# 长文章生成引擎

本文件是转换skill 第4步"转换"的深度参考,提供长文章(3000-15000字)的结构控制能力。借鉴自媒体创作与长篇小说控盘经验,简化为适合二次元知识转换的6维度构思、段落规范与去AI味修订。

## 6维度内容构思

动笔前完成6维度构思。这个思考过程是内在的,不展示给用户,但直接决定文章质量。

### 1. 核心记忆点

读者读完文章后只记住的一句话。好的核心记忆点:
- 能用一句话说清
- 读者看完会产生"原来如此"的反应
- 与知识点本质强绑定

问自己:如果读者只能记住这篇文章的一句话,那句话是什么?

### 2. 情感曲线

像设计电影节奏一样设计文章的情感走向:
- **开头**:制造张力(悬念、冲突、反直觉的事实)
- **中段**:在"紧张-释放"之间交替(给出信息后留下新问题)
- **高潮**:核心知识的最强表达,情感最浓烈的时刻
- **结尾**:余韵(让读者带着某种情绪离开)

避免通篇高亢或通篇平淡。二次元风格中,高潮常对应角色的"觉醒时刻"或"顿悟瞬间"。

### 3. 论证多样性

避免通篇用同一种方式解释知识。交替使用:
- 角色对话(用二次元角色的口吻解释)
- 场景类比(用异世界/校园/咖啡馆场景类比)
- 反问设问(角色内心的疑惑)
- 正面论证与反面论证(角色尝试错误路径后找到正解)

不同论证方式的切换让读者保持注意力。

### 4. 金句

2-3个可独立传播的记忆锚点。好金句:
- 表达精准,没有多余的字
- 有节奏感(对仗、转折)
- 能脱离上下文独立传播
- 包含知识洞见(不是口号)

自然嵌入文章的开头、高潮和结尾,不硬塞。

### 5. 视角切换

在文章中策略性切换视角:
- **第一人称**:角色亲历视角,增强代入感(用于故事段)
- **第二人称**:直接对话,增强参与感(用于建议/引导段)
- **第三人称**:旁观视角,增强客观感(用于知识分析段)

视角切换是高级技巧,比全篇固定视角更有表现力。

### 6. 钩子闭环

开头埋钩子,结尾回收,形成闭环:
- 开头抛出悬念或问题(角色遇到困境)
- 中段逐步揭示(角色探索过程)
- 结尾回收钩子(困境解决,呼应开头)

钩子闭环让文章有头有尾,而非散漫的片段堆砌。

## 段落与节奏规范

### web-serial-natural 段落模式

借鉴网文连载的自然段落风格:
- 叙事段落 **2-4句** 为一段
- 单句段落仅用于:强调、揭示、震惊、场景切换、钩子
- 单句段落不应连续出现(连续单句=节奏失控)

### 节奏控制

- 长文中每 **800-1000字** 设置一个小高潮或转折点
- 每个小高潮后给读者"呼吸空间"(过渡段)
- 避免信息密度均匀分布,要有疏密交替

### 对话格式

- 角色对话用「」包围(二次元轻小说风格)
- 对话标签简洁(「XX说」「XX道」可省略,用动作替代)
- 连续对话可不带标签,靠语气区分角色

## 去AI味三步修订

文章初稿完成后,执行三步修订。目标是让文章读起来像人写的二次元轻小说,而非AI生成的说明文。

### 第1步:去套话

删除以下AI模板句式:
- "值得注意的是""综上所述""不难发现"
- "首先...其次...最后..."的机械结构
- "这不仅仅是...更是..."的空泛升华
- "让我们一起来探讨..."的课堂腔
- 任何读起来像教科书导论的开头

### 第2步:去过度术语

- 压低普通读者难懂的专业术语
- 保留知识必需的核心术语(用角色对话解释其含义)
- 用二次元场景替代抽象概念(如用"侦探推理"替代"贝叶斯推断")
- 专业模式下可保留更多术语,但仍需在对话中解释

### 第3步:恢复语感

恢复二次元轻小说语感:
- 角色口头禅(如"欸?""真的假的?!""原来如此...")
- 语气词(呀、呢、嘛、哦、欸)
- 轻小说句式(短句、倒装、内心独白)
- 角色专属语气(每个角色有辨识度的说话方式)

确保文章通俗易懂,不因篇幅增加而转为学术腔。

## 三层字数适配

### 简约模式(≤1500字)

- 结构:1个核心场景 + 1段对话 + 1个金句
- 6维度:只取核心记忆点 + 钩子闭环,其余维度不强制
- 段落:3-5个自然段
- 不堆砌维度,保持精简

### 适中模式(3000-6000字)

- 结构:完整起承转合(开头钩子→中段论证交替→高潮→结尾余韵)
- 6维度:全部6维度均需体现
- 金句:2-3个,分布在开头、高潮、结尾
- 段落:15-25个自然段,每800-1000字一个小高潮
- 钩子闭环:开头埋钩子,结尾回收

### 专业模式(10000-15000字)

- 结构:多线叙事(知识主线 + 角色线 + 场景线)+ 章节式分段
- 分段:每2000-3000字一个章节段落,带小标题
- 6维度:全部6维度 + 多线交织
- 伏笔:埋设2-3个伏笔,在文章后段回收
- 深度推导:保留知识的完整推导链,用角色探索过程呈现
- 金句:3-5个,每个章节段落至少1个
- 钩子闭环:多层钩子(总钩子 + 每章小钩子)
