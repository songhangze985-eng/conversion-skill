# 叙述边界与切中要害极简白话指南（`narrative-boundary-and-gist`）

本指南确立 `conversion-skill` 的**叙述边界铁律**与**高概括切中要害模式**。通俗易懂绝不等于编造一篇拖泥带水的长篇小说，而是用读者最熟悉的**日常话术（如常玩的游戏黑话、生活直觉、职场话术）做一针见血的类比映射**；当面对**反复强调同一观点的文章**或**文言文**时，更应直接砍掉故事外皮，用最简洁的白话文切中要害向读者阐述。

---

## 一、设定叙述边界：不是长篇大论讲故事，而是日常话术映射

很多低质量的通俗解释之所以让人读不下去，是因为把「讲人话」误解成了「写注水小说」——花三百字描写主角推开橡木门、窗外下着雨、端起咖啡陷入沉思，讲了半天还没碰到核心机制。

### 1. 三条硬性叙述边界

1. **零背景注水**：严禁在正文里铺垫与机制毫无关系的天气、外貌、身世、寒暄或架空世界观（如 `「在很久很久以前」`、`「阳光透过窗户洒在」`、`「端起一杯冒着热气的咖啡」`）。每一句话都必须推进「痛点、动作、限制、结果」中的一个环节。
2. **单点类比不超两句**：日常话术类比的作用是「点醒直觉」。一个概念用 1–2 句精准的日常话术对位即可，点透立刻收手，绝不把比喻本身扩写成肥皂剧。
3. **顺应用户习惯选话术（`--habit <gaming|daily|workplace>`）**：根据读者的日常习惯切换最顺耳的话术体系。比如面对常玩游戏的读者，直接用游戏高频机制词对位，比编造生硬的童话故事清晰十倍。

### 2. 用户习惯话术映射速查表（以游戏玩家习惯 `gaming` 为例）

| 抽象机制 / 逻辑关系 | 游戏玩家常用话术映射（`gaming`） | 日常生活话术映射（`daily`） |
| --- | --- | --- |

## 二、高概括直述模式：对重复观点文章与文言文直接切中要害

并非所有输入都适合打比方。遇到以下两类文本时，系统自动将叙述边界收紧为 `direct_pithy_gist`（直击要害·极简白话模式），省去一切剧情包装，用最简练的白话直接亮底牌：

### 1. 重复强调观点的文章（脱水去重，一句话亮主旨）

很多议论文、演讲稿或行业评论会用五六个段落、正反排比和车轱辘话（如 `「换句话说」`、`「再举个例子」`、`「从另一个角度看」`）反复强调同一个观点。

- **处理准则**：先用切中观点的关键词筛选工具（`scripts/screen-keywords.ts`）剥离修辞噪音，锁定真正承载立场的 3–5 个靶心词（尤其聚焦于「不是……而是……」「归根结底」「核心在于」后半句的肯定主张），直接用 **1 句最简白话结论 + 核心抓手词**向读者交代清楚，绝不跟着原文一起绕圈子。

### 2. 文言文与古籍经典（自建 JSON 知识库破译 + 最简白话阐述）

文言文的难点在于「古今异义词踩坑」与「铺陈排比掩盖了最后一句真话」（例如《劝学》铺陈了青出于蓝、冰寒于水、登高博见、顺风而呼，全篇真正切中要害的其实就最后一句 `「君子生非异也，善假于物也」`）。

- **自建文言文翻译 JSON 知识库（`assets/knowledge/classical-chinese-kb.json`）**：
  - 内置 30 条高频文言立论/判断/因果/反诘等句式（如 `「…者，…也」`、`「故曰」`、`「是以」`、`「君子曰」`、`「臣闻」`、`「然则」`），自动按立论信号权重锁定文言文里的核心观点句。
  - 内置高频文言实词与古今异义防坑词典（如 `「劝=勉励」`、`「假：假寐=假装，善假于物=借助」`、`「卑鄙=地位低见识浅」`、`「痛恨=痛心遗憾」`、`「所以=用来…的手段/原因」`、`「虽然=虽然这样」`、`「妻子=妻子和儿女」`），精准拦截望文生义。
  - 内置经典名篇极简白话直译与游戏/日常/职场三栖话术映射，对未收录的古文自动按句式规则与实词词典组合破译。

## 三、工程工具调用方式

1. **独立运行切中观点的关键词筛选与文言文白话破译工具**：
   运行 `bun run screen-keywords -- "<文本或文件>" --habit gaming --markdown`，即可直接输出「最简白话阐述 + 切中观点的关键词权重表 + 古今异义防坑对照 + 游戏/日常话术一秒映射」。
2. **在输入预检中联动识别**：
   运行 `bun run validate-input -- "<文本>" --screen-keywords --habit gaming`，自动在预检 JSON 中返回 `is_classical_chinese`、`is_repetitive_argument`、`detected_user_habit`、`narrative_mode` 与完整筛选报告。
3. **在交稿验收中检查叙述边界或一键导出极简白话卡**：
   运行 `bun run check-output -- <draft.md> --emit-gist - --habit gaming` 可直接导出切中要害的极简白话阐述报告；同时 `evaluateNarrativeBoundary` 会自动拦截长篇故事注水并打上 `长篇剧情注水` 标签。
