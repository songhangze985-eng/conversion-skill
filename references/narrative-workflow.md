# 记叙文写作工作流

在事实清单与场景映射完成后，按以下五步将干瘪的步骤转化为一篇自然流畅的记叙文（默认正文 ≤ 800 字）。

## 1. 立处境（起因）

先问自己：在真实生活里，什么人会在什么情况下遇到原机制要解决的那个麻烦？
- 用两三句话交代清楚人物眼前的局面和手头的初始材料（对应**输入**）。
- 可以顺着时间从头写起；如果结果很有反差感，也可以先亮出最终局面，再自然倒叙回最初那一步。

## 2. 推行动（经过）

顺着机制真实的先后顺序写人物怎么动手处理：
- 每一步机制对应一个看得见的动作和变化（单据盖了章、队伍分成了两列、水位降了一格）。
- 尽量用具体动词推动画面，少用抽象形容词。需要点出核心概念时，先写完动作，再顺势带出名字。

## 3. 撞边界（关键转折 / 约束）

这是整篇记叙文的「戏眼」。不要把约束条件写成旁白说明，而要让人物在操作中**结结实实地撞上一次限制**：
- 比如：想直接往里填，却发现格子已经锁死；想继续往下分，却发现手里只剩最后一张牌。
- 借人物的反应或一句简短对话，把「为什么停在这儿、硬闯会出什么错」自然点透。

## 4. 落结果（结局与点睛）

写清这一番操作之后，现场最终变成了什么样（对应**输出**）。最后用一句干净、有分量的收束句，把这段经历提炼成外行一句话就能带走的底层规律。

## 5. 朗读自检

通读全文：
- 删掉任何像「说明书填空」或「括号备注」的生硬句子。
- 确认外行读完这段故事，能清楚复述出「原本什么样 → 怎么一步步做的 → 在哪儿被规矩拦住了 → 最后得到了什么」。
