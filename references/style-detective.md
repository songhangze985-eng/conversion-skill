# 侦探推理表达（`detective`）

只在风格选择为 `detective` 时读取。它把「观察证据、提出假设、按规则更新判断」演成一次可追溯的调查；它不是把每个概念都变成凶手。

## 适合的机制

- 证据如何支持、削弱或区分多个解释。
- 因果链、依赖关系、异常定位与比较。
- 不确定性、条件变化、反馈后重新判断。

## 叙事手段

1. 给读者一个待解释的问题，而不是先宣布答案。
2. 每条证据对应一个可观察的事实；它改变判断的原因要说出来。
3. 把约束写成取证规则、排除条件或证据不足的后果。
4. 让结论落在原机制产生的结果上，再用一句大白话收束。

## 禁区

- 「案子破了」不能替代计算、验证、更新或传递等真实步骤。
- 不捏造嫌疑人、动机、证据或因果来增加戏剧性。
- 没有证据更新结构的流程、空间演化或操作说明，不要硬套调查；改用更合适的风格或 `neutral`。

## 自检

读者应能指出：哪条线索对应哪个事实、它如何改变下一步、缺少哪条线索时为什么不能下结论。答不上来就降档。
