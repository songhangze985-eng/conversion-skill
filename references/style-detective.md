# 侦探推理表达（detective）

当所讲机制涉及**「从现象反推原因、依证据更新概率、排除干扰项或定位异常」**时使用。它的核心魅力在于带着读者一起抽丝剥茧，而不是摆架子耍酷。

## 叙事四步

1. **案发悬念（提出反直觉问题）**：用一桩看似板上钉钉、实则暗藏陷阱的疑案或异常现象开场，勾起读者的好奇心。
2. **亮出底牌与新物证（输入与状态）**：写清调查员最初的判断（先验/初态），以及现场新发现的关键痕迹（输入信号/新证据）。
3. **交叉验真（核心机制与约束）**：这是推理的核心——不能看见脚印就抓人，必须同时核对「如果是他干的，留下这脚印的概率有多大」以及「满大街别人穿同款鞋的概率有多大」。把约束条件写成铁打的办案纪律（如孤证不立、基准率为零时无法更新）。
4. **水落石出（输出与规律收束）**：得出更新后的判断，并用一句干净的大白话点破这背后的通用推理法则。

## 禁区

- 绝不写「侦探灵光一闪直接指认凶手」或「嫌疑人突然良心发现招供」，所有结论必须由证据计算或规则排除一步步推出来。
