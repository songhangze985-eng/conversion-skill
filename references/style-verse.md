# 现代短诗表达（verse）

只在用户明确点名「写成诗 / 诗篇」时使用。这里的诗是**凝练、有节奏感的现代说理短诗**——用干净的意象和递进的回环把机制的脉络刻进读者脑海，绝不是堆砌古风辞藻或凑打油诗韵脚。

## 适合的机制

- 具有鲜明节奏感、往复迭代、分治回环或状态转换的机制（如递归、二分查找、状态机、潮汐般的周期同步）。
- 核心规则简洁有力，适合通过诗行的重章叠句来强化印象。

## 叙事与诗意原则

1. **意象专一**：全诗围绕一个核心生活意象展开（如折纸、分沙、渡河、点灯），不东一榔头西一棒槌地换典故。
2. **动作立行**：每一行落在一个清晰的动作或状态变化上，短促有力，不写冗长的修饰从句。
3. **回环递进**：重复出现的诗句必须带着状态往前走（第一次是起点，第二次是深入，最后一次是抵达边界后的静止），而不是原样复制粘贴。
4. **诗后点睛**：诗篇结束后，另起一行附一句清澈的大白话，把诗中意象与真实机制直接锚定。

## 禁区

- 不用生僻字、古文典故或为了押韵而扭曲语序（倒装）。
- 不为了精简字数而漏掉原机制的终止条件或核心约束。
- 若机制本身是繁琐的多分支配置流程，不适合入诗，应主动降档为 `neutral`。
