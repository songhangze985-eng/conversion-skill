# 四步交互流水线与首轮秒懂直出多轮示范

本文档承接 `SKILL.md` 中的交互链路规范，提供三组端到端多轮对话参考。所有范例均遵循「首轮先给高密度直觉价值、过程默认折叠在幕后、按语境生成追问引导」的交互准则，避免用繁琐问卷阻断读者的理解节奏。

## 范例一：首轮秒懂直出与文言文一词多义消歧（蒲松龄《狼》与荀子《劝学》对比）

当读者首次接入并发送打招呼语句时，助手原样输出固定亲和问候语：「你好啊，我可以帮你把你不懂的话尽量转换成你能听懂的，告诉你！可以发我语句或文件来处理哦！文言文、文献这些都可以尝试呀」。随后读者直接发来两句带「假」字的古文：「乃悟前狼假寐，盖以诱敌」与「君子生非异也，善假于物也」，询问两处「假」字为何意思完全不同。

助手在幕后自动激活文言文语境消歧规则，不在首轮抛出多级菜单盘问，而是直接交付切中要害的白话结论：前一句里的「假寐」受动物动作语境约束，意思是假装闭眼打瞌睡，整句点破前面的狼装睡其实是为了引诱屠户分神；后一句里的「善假于物」受介词结构「假于」约束，意思是擅长借用外部现成工具与规律，整句说明高手的底子跟普通人没两样，差距全在会不会借力。两处「假」字一个指伪装迷惑，一个指借用赋能，一旦按现代汉语的真假生搬硬套就会彻底读反。正文末尾附上固定省略提示「过程已省略（要不要把过程拉出来给你看？）」与贴合古文语境的追问引导「你可以试试说：把逐字古今异义防坑表拉出来看看，或用日常/游戏的理解方式打开」。

当读者在下一轮回复「把过程拉出来看看」时，助手再展开幕后的文言句式结构、古今异义对照表与信达雅三阶拆解，让首轮阅读保持清爽，深度核验有据可查。

## 范例二：场景转译下级分流、具体游戏点名与网络热梗直说（令牌桶限流与异常冒泡）

当读者发来工程机制问题「高并发架构里的令牌桶限流和服务熔断到底怎么配合防雪崩，我想换个熟悉的方式听懂」并主动选择场景转译分支时，助手询问：「你是选 `【游戏】`、`【网络热梗】` 还是 `【日常话术】` 呢？」。若读者选择日常话术，助手不再追问任何下级问题，直接用地铁早高峰闸机按固定间隔放人与跳闸保护器自动断电的日常画面完成交付。若读者选择网络热梗，考虑到读者无需分辨复杂的语用学分类，助手直接请读者说出具体热梗名称（如「甩锅」「草台班子」或「硬控」），拿到热梗词条后立即对齐因果链条输出结果。

若读者选择游戏并回答「王者荣耀这款手游」，助手立即调取知识库中该游戏的机制槽位，围绕「令牌桶限流」与「服务熔断」动态撰写同构解释：令牌桶就像百里守约二技能攒狙击子弹，系统每隔几秒往枪膛塞一颗子弹、最多攒满三颗，团战爆发时能一口气三连狙打光库存，打空后只能等冷却读秒，既放行短时爆发又防止算力蓝条被瞬间抽干；服务熔断则像后排被集火时触发「名刀司命」锁血并按下「辉月金身」，当报错率冲破红线就立刻焊死大门秒回兜底提示，等冷却窗口过去再放一发普攻流量试探下游有没有回血。正文收尾同样附上「过程已省略（要不要把过程拉出来给你看？）」与游戏切换提示。

## 范例三：仿真世界知名作家写法与冷峻短句文体豁免（死锁机制）

当读者在深度叙事分支中要求「仿真古龙或者鲁迅的写法，把操作系统里的死锁四个必要条件写成故事」时，助手读取知名作家笔法规约卡中的目标概念槽位，绝不照搬知识库里其他主题的静态样本文本，而是针对「互斥、持有并等待、不可抢占、循环等待」四个条件现场创作。

在仿真古龙冷峻武侠短句笔法时，助手采用高张力环境留白与干脆利落的动作推进：窄巷只有一扇铁门，门闩在张聋子手里，钥匙却在李瞎子腰间；谁也不肯松开手里的半截命脉，谁也没本事硬夺对方的家伙，四只眼睛在冷风里死死盯成一圈死结，直到天亮也没有人能迈出窄巷半步。配合 `--author-profile 古龙` 校验档位，系统在放行文学性短促留白段落的同时，依然严格拦截空洞套话、表情包污染与静态贴标签伪类比，并在读者追问幕后过程时完整展开四列映射表与适用边界。
