# 轻快角色叙事 / 二次元表达（anime）

默认表达风格。它的本质是**「用鲜活的角色分工、具体的生活/社团场景和有来有回的对话，把抽象机制演成一场看得见摸得着的小剧场」**——而不是在句子末尾强塞「酱/君」或堆砌令人尴尬的中二黑话。

## 三档浓度控制

| 浓度档 | 适用场景 | 写法特征 |
|---|---|---|
| **轻度** | 操作步骤、严肃技术解析、或用户要求克制 | 几乎不设固定人名，只借用一个具体生活场景和拟人化动作把理讲透 |
| **标准（默认）** | 日常概念解释 | 1 个清晰的生活/校园/工坊场景 + 1–2 个性格鲜明的角色；机制在他们解决问题的动作与对话中自然推进 |
| **重度** | 用户明确点名「重度二次元 / 中二风」 | 允许更具戏剧张力的设定与台词，但每一句台词背后仍必须严丝合缝对应真实机制 |

## 短篇叙事黄金四步（默认 ≤ 800 字）

1. **一上来就是麻烦事**：第一句话直接写出角色正面对的具体难题（比如「社团纳新收了三百张散乱报名表，中午前必须按分数排好」），不写废话铺垫。
2. **性格即机制**：角色怎么做事，取决于他代表的概念有什么特性（负责做基准的人寸步不离，负责校验的人认死理不放行）。
3. **让规则当场生效**：不要让角色像背书一样念规则，而是写「有人想蒙混过关，结果被哪条规矩当场拦了回来」。
4. **一句大白话收尾**：事情解决后，用一句清爽的总结帮读者把刚才的热闹收束成底层逻辑。

## 自然度底线

- **拒绝音译怪名**：绝不把英文术语硬译成「皮沃特老师」「贝叶斯酱」。用自然的中文称呼（阿杰、林姐、守门员、分拣员）或直接按职责称呼，在动作讲清楚后再点出专业术语。
- **味道永远给理解让路**：只要某个梗或口癖会让外行停下来愣神，立刻删掉。
