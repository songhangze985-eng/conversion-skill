## 示例 1:贝叶斯定理(数学 / 概率)

### Input

> 贝叶斯定理:$P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$

### 公式含义(自然语言先解释)

贝叶斯定理公式 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$ 描述:在已知事件 B 已经发生的前提下,事件 A 发生的概率(记作 $P(A|B)$,称为"后验概率"),可以由 A 的先验概率 $P(A)$、在 A 成立时 B 发生的似然 $P(B|A)$、以及 B 的边缘概率 $P(B)$ 计算得出。简言之:**看到新证据 B 后,我们对 A 的信念应当如何更新。**

### 1. 理解

- **原文含义复述**:贝叶斯定理是一个"根据新证据更新旧判断"的公式。它告诉我们,在观察到 B 之后,A 的可能性 = (B 在 A 下有多容易出现 × A 原本就有多可能) ÷ (B 总体有多容易出现)。
- **核心难点**:理解"先验 / 后验"的相对关系,以及为什么分母是 $P(B)$——它起"归一化"作用,让结果仍是一个合法概率。
- **歧义与假设**:无显著歧义。

### 2. 提炼

- **关键概念 / 变量**:
  - $P(A)$:先验概率,A 原本(没有任何证据时)发生的可能性。
  - $P(B|A)$:似然,若 A 为真,B 出现的可能性。
  - $P(B)$:边缘概率,B 总体出现的可能性(归一化项)。
  - $P(A|B)$:后验概率,看到 B 之后 A 的更新可能性。
- **关系**:$P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$,即"后验 = (似然 × 先验) / 边缘"。
- **约束条件**:$P(B) > 0$(分母不能为零);所有概率取值在 $[0,1]$。

### 3. 抽取

- **映射关系**:

  | 知识概念 | 故事元素 | 对应理由 |
  |---|---|---|
  | $P(A)$ 先验 | 侦探"贝叶斯酱"对嫌疑人 X 的初始怀疑度 | 没有证据时的初始判断 |
  | $P(B\|A)$ 似然 | "若 X 真是凶手,现场会出现脚印 B"的概率 | A 为真时证据出现的可能 |
  | $P(B)$ 边缘 | 脚印 B 总体出现的可能(凶手/非凶手都可能留下) | 归一化,排除"别人也会留"的干扰 |
  | $P(A\|B)$ 后验 | 看到脚印 B 后,贝叶斯酱对 X 的新怀疑度 | 更新后的判断 |
  | 约束 $P(B)>0$ | 故事规则:"证据必须确实出现,否则无法推理" | 没有脚印就没法更新怀疑度 |

- **类比机制说明**:侦探每获得一条新证据,就按"这条证据在凶手身上有多常见 × 嫌疑人原本多可疑 ÷ 这条证据总体多常见"来改写怀疑度——这正是贝叶斯更新。机制同构(见 `mapping-principles.md` 神似检查)。

### 4. 转换(标准档 · 二次元轻小说风)

> 异世界侦探社,雨夜。

「贝叶斯酱,又有案子了。」前辈把一份卷宗拍在桌上。

名叫贝叶斯的少女侦探揉了揉眼睛。她对嫌疑人 X 的初始怀疑度,只有 **三成**——这就是她的"先验",还没看到任何证据前的直觉。

「不过……」她蹲下身,盯着泥泞里的脚印,「这是 X 那双限量版靴子留下的纹路。」

这就是证据 **B**。贝叶斯酱在心里飞快计算:**假如 X 真是凶手**,他留下这种脚印的可能性高达九成(似然 $P(B|A)=0.9$);可问题是,这双靴子在全市卖了不少,**就算凶手不是 X**,也可能有别人留下同样的脚印——所以脚印 B 总体出现的概率 $P(B)$,其实并不低。

「关键就在分母。」她咬着笔杆喃喃自语,「我要把'别人也会留脚印'这部分干扰扣掉……」

> 【伏笔】前辈随口提了一句:「听说这靴子限量一百双,光这个街区就住了三双的主人。」

于是她在笔记本上写下:

$$\text{新怀疑度} = \frac{\text{脚印在凶手身上的常见度} \times \text{原本的怀疑度}}{\text{脚印总体的常见度}}$$

笔尖一顿,数字跳出:**六成八**。

「嫌疑人 X 的嫌疑,从三成升到了六成八。」贝叶斯酱合上笔记本,「这就是'后验'——看到证据之后,更新过的判断。」

> 【反转揭晓】前辈一愣:「才六成八?这靴子不是限量版吗,我以为会飙升到九成。」贝叶斯酱摇头:「限量≠在这个街区罕见。$P(B)$ 不小,后验自然不会太高——这正是分母的意义:别被'看起来稀有'骗了。」

> (本段满足:角色化、场景化、对话化、拟人化、伏笔/反转,共 5 项 ≥ 3 项)

### 知识点校验

贝叶斯定理公式为 $P(A|B) = \dfrac{P(B|A)\,P(A)}{P(B)}$,表示在观测到事件 B 后,事件 A 的后验概率由先验 $P(A)$ 与似然 $P(B|A)$ 的乘积,再除以 B 的边缘概率 $P(B)$(归一化项,$P(B)>0$)得到,本质是"用新证据对旧信念进行更新",要求 $P(B)>0$ 且所有概率均在 $[0,1]$ 区间。

## 示例 2:快速排序(算法)

### Input

> 快速排序:选一个 pivot,比它小的放左边,大的放右边,递归处理两边。

### 1. 理解

- **原文含义复述**:快速排序是一种分治排序算法。先从数组里挑一个元素当"基准"(pivot),然后把剩下元素按"比 pivot 小"和"比 pivot 大"分成两组(pivot 自身位置已定),再对左右两组分别重复这个过程,直到每组只剩一个元素,整个数组就有序了。
- **核心难点**:
  1. 理解"分区"这一步——pivot 一次到位,后续不再参与递归。
  2. 理解"递归"的终止条件——组内 ≤1 个元素时停止。
  3. 容易误以为 pivot 一定是中位数(其实任意选都行,只是效率不同)。
- **歧义与假设**:无歧义。补充假设:此处描述的是经典原地快排的语义,不深究具体实现细节(如 Lomuto / Hoare 分区方案)。

### 2. 提炼

- **关键概念 / 变量**:
  - **pivot(基准)**:被选出来用于分区的元素,分区后位置最终确定,不再参与后续递归。
  - **分区(partition)**:把元素按"比 pivot 小"和"比 pivot 大"分成左右两组的操作。
  - **递归(recursion)**:对左右两组分别重复"选 pivot → 分区"的过程。
  - **终止条件**:当某个子组内元素个数 ≤ 1 时,该组不再递归(已天然有序)。
- **关系**:整体流程 = 选 pivot → 分区 → 对左右子组递归;递归以"组内 ≤1 元素"为终止条件。
- **约束条件**:
  - 终止条件:子组规模 ≤1 时停止。
  - pivot 分区后位置确定,不进入下一层递归。
  - 每次分区后,左右两组规模之和 = 原组规模 −1(扣掉 pivot 本身)。

### 3. 抽取

- **映射关系**:

  | 知识概念 | 故事元素 | 对应理由 |
  |---|---|---|
  | pivot(基准) | 运动会裁判"皮沃特老师"定下的"达标线" | 一个被选中的标准,用它把人分两组 |
  | 分区(partition) | 裁判吹哨,达标的人站左边,不达标的人站右边 | 按与基准的比较结果分组 |
  | 递归(recursion) | 对左右两组再分别选拔(再选达标线、再分组) | 自我嵌套重复同样流程 |
  | 终止条件 | 一组里只剩一个人时,不比了,直接定名次 | 规模 ≤1 时停止 |
  | pivot 不再参与递归 | 定达标线的人本轮不比了,名次已定 | pivot 分区后位置确定 |
  | 左右两组规模和 = 原组 −1 | 定线的人站到最终位置,其余人继续分 | 每次分区扣掉 pivot 本身 |

- **类比机制说明**:校园运动会选拔赛中,裁判每轮定一条达标线,达标 / 不达标分两组,达标线对应的人本轮名次锁定不再参与,两组各自再定新达标线继续分,直到某组只剩一人。这与快排的"选 pivot → 分区 → 递归 → 终止"完全同构。

- **神似检查**:
  - 选 pivot ↔ 定达标线 ✓
  - 比 pivot 小 / 大分两区 ↔ 达标 / 不达标分两组 ✓
  - pivot 位置锁定 ↔ 定线者本轮名次已定 ✓
  - 对左右递归 ↔ 对两组再选拔 ✓
  - 终止:组内 ≤1 ↔ 一组只剩一人 ✓
  - 机制完全同构,神似成立。

- **保真检查**:
  - 约束"组内 ≤1 终止"→ 故事规则"一组只剩一人就不比了" ✓ 可嵌入
  - 约束"pivot 不再递归"→ 故事规则"定线的人本轮名次锁定" ✓ 可嵌入

### 4. 转换(标准档 · 二次元轻小说风)

> 樱丘高中,运动会预选赛场,午后阳光晒得跑道发烫。

「喂,皮沃特老师,这一百个选手怎么排出名次啊?」新生干事小快抱着一沓报名表,额头冒汗。

被叫做皮沃特的中年裁判吹了声口哨,随手从名单里挑出一个名字:「就他了——这一轮的达标线,是他跑出来的 13 秒 5。」

「达标的站左边,没达标的站右边!」皮沃特老师一抬手,选手们呼啦啦分成两拨。

小快数了数:「左边四十二个,右边五十七个。」

「那个 13 秒 5 的同学呢?」小快左看右看。

「他?」皮沃特老师头也不抬,「他这一轮名次就定了——卡在四十二和五十七之间。**达标线本身,这一轮就不比了。**」

> 【拟人化 + 角色化】定达标线的人本轮名次锁定,正是"pivot 分区后位置确定,不再参与递归"。

「那接下来呢?」

「左边四十二个,自己再选一个达标线,再分;右边五十七个,也一样。」皮沃特老师打了个哈欠,「**一组一组往下分,直到某一组只剩一个人——那就不比了,名次自然就定了。**」

小快皱眉:「就……一直分下去?」

「一直分下去。」皮沃特老师点头,「每一轮,达标线那个人名次锁定,剩下的人分两组继续。你想想,最后是不是每个人都被某条达标线'卡'在一个确定的位置上?」

小快愣了愣,忽然眼睛一亮:「……对!因为每轮都有一部分人(达标线)被'钉'死,剩下的人继续分,迟早每个人都被钉住!」

> 【对话化】小快作为提问角色,替读者问出"一直分下去会不会乱",皮沃特老师的回答点出快排正确性的直觉。

「不过老师,」小快又问,「达标线随便选都行?」

「随便选。」皮沃特老师耸肩,「选得好,左右两边人数差不多,分得快;选得差,一边满一边空,就慢——但**结果一定是对的**,只是快慢不同。」

> 【伏笔 / 反转】埋下"选 pivot 影响效率但不影响正确性"的伏笔,后续可展开"最坏情况 O(n²) vs 平均 O(n log n)"。

> (本段满足:角色化、场景化、对话化、拟人化、伏笔/反转,共 5 项 ≥ 3 项)

### 知识点校验

快速排序是一种分治排序算法:每轮从待排序区间中选一个元素作为 pivot,将剩余元素按"小于 pivot"和"大于 pivot"分为左右两组(pivot 自身位置在此步确定且不再参与后续递归),然后对左右两组递归执行同样流程;递归终止条件为子组元素个数 ≤ 1。pivot 的选取任意,影响效率但不影响正确性,平均时间复杂度 $O(n \log n)$,最坏 $O(n^2)$(发生在每次 pivot 都选到最值导致分组极度不平衡时)。

## 示例 3:Raft 共识算法(分布式架构)

### Input

> Raft:通过 leader 选举和日志复制实现分布式共识,多数派确认即提交。

### 1. 理解

- **原文含义复述**:Raft 是分布式系统中让多个节点对"接下来执行什么操作"达成一致的算法。它把流程拆成两件事:(1) 选出一个 leader(领袖)负责主导;(2) leader 把操作日志复制给所有 follower(跟随者),当**多数派**(过半数)节点确认收到这条日志后,这条日志才算"提交"(commit),即被系统正式接受。leader 故障时,剩余节点重新选举新 leader。
- **核心难点**:
  1. 为什么是"多数派"而不是"全部"?——多数派允许少数节点宕机仍能推进,保证可用性。
  2. leader 和 follower 的角色切换——leader 挂了怎么办?新 leader 怎么补齐日志?
  3. "提交"的含义——提交=不可撤销,这是共识的安全边界。
- **歧义与假设**:无显著歧义。补充:此处不展开"任期(term)""日志匹配"等细节,聚焦"选举 + 复制 + 多数派提交"的主干机制。

### 2. 提炼

- **关键概念 / 变量**:
  - **leader(领袖)**:被选出的主导节点,负责接收客户端请求并向 follower 同步日志。
  - **follower(跟随者)**:被动接收 leader 日志的节点。
  - **candidate(候选人)**:选举阶段参与竞选的节点(follower 升级为 candidate 参选)。
  - **日志复制(log replication)**:leader 把操作日志发给所有 follower,follower 确认后回 ack。
  - **多数派(majority)**:超过半数节点。日志被多数派确认才算"提交"。
  - **提交(commit)**:日志被多数派确认后的状态,不可撤销,代表系统正式接受该操作。
  - **选举(leader election)**:leader 故障或初始启动时,follower 转为 candidate,获得多数派选票即当选新 leader。
- **关系**:
  - 选举 → 产生 leader(多数派选票当选)。
  - leader 接收请求 → 复制日志给 follower。
  - 多数派 follower 确认 → leader 提交该日志。
  - leader 故障 → 触发新一轮选举。
- **约束条件**:
  - 多数派门槛:过半数节点同意才有效(选举 / 提交均如此)。
  - 一个任期(term)内最多一个 leader。
  - 已提交的日志不可丢(安全性)。

### 3. 抽取

- **映射关系**:

  | 知识概念 | 故事元素 | 对应理由 |
  |---|---|---|
  | leader(领袖) | 学生会"议长" | 主导议事、对外发声 |
  | follower(跟随者) | 普通议员 | 听议长的、举手确认 |
  | candidate(候选人) | 宣布参选的议员 | 从议员转为竞选者 |
  | 选举(leader election) | 议会投票选议长 | 多数派选票当选 |
  | 日志复制 | 议长把议案抄发给所有议员,议员誊抄进自己的议事本 | leader 同步日志给 follower |
  | 多数派确认 | 过半数议员举手说"我抄完了" | 多数派 ack |
  | 提交(commit) | 议长敲槌:"议案通过,记入校史,不可撤销" | 多数派确认后正式生效 |
  | leader 故障 | 议长突然病倒 / 离场 | 节点宕机 |
  | 重新选举 | 议员们重新投票选新议长 | 触发新一轮选举 |
  | 约束:多数派门槛 | 故事规则:"必须过半数议员举手,决议才算数" | 过半数才有效 |
  | 约束:一任期一 leader | 故事规则:"一届议会只有一位议长" | 一个 term 一个 leader |
  | 约束:已提交不可撤销 | 故事规则:"记入校史的不能涂改" | 已 commit 不可丢 |

- **类比机制说明**:议会中,议员们先投票选出一位议长(leader 选举,多数派当选),议长把每条议案抄发给所有议员(日志复制),当过半数议员举手表示"我已誊抄"(多数派确认),议长就敲槌宣布议案通过并记入校史(提交,不可撤销)。议长若病倒(leader 故障),议员们重新投票选新议长(重新选举)。机制完全同构。

- **神似检查**:
  - 选举(多数派选票)↔ 议会投票(过半数当选)✓
  - leader 主导 ↔ 议长主导议事 ✓
  - 日志复制 ↔ 议长抄发议案、议员誊抄 ✓
  - 多数派确认 ↔ 过半数议员举手 ✓
  - 提交不可撤销 ↔ 记入校史不可涂改 ✓
  - leader 故障 → 重选 ↔ 议长病倒 → 重选 ✓
  - 机制完全同构,神似成立。

- **保真检查**:
  - 约束"多数派门槛"→ 故事规则"过半数举手才算数" ✓
  - 约束"一任期一 leader"→ 故事规则"一届一位议长" ✓
  - 约束"已提交不可撤销"→ 故事规则"记入校史不可涂改" ✓
  - 全部可嵌入,保真通过。

### 4. 转换(标准档 · 二次元轻小说风)

> 樱丘高中学生会议事厅,圆顶吊灯下,五张红木长桌围成一圈。一共五位议员,今天要选出新议长。

「上一任议长转学了。」议员甲站起来,清了清嗓子,「我宣布参选!请大家把票投给我。」

他从"普通议员"变成了"候选人"——按校规,想当议长的人,得先自己举手宣布。

「我也参选!」议员乙也站了起来。

投票开始。五个人,过半数就是三票。议员甲拉到了三票(包括自己),超过了半数。

> 【拟人化 + 角色化】"获得多数派选票即当选"= 议员甲拿到过半数票成为议长。

「我当选了。」议员甲坐上议长席,「从现在起,这届议会只有我一位议长。」

> 【约束可视】"一届议会只有一位议长" = 一个 term 内最多一个 leader。

上任第一天,有同学来学生会提了个议案:"把图书馆开放时间延长到晚上十点。"

议长甲没急着宣布,而是拿出一张议案纸,工工整整抄了五份,分发给五位议员——包括自己一份。

「请大家誊抄进各自的议事本,抄完举手。」

议员们低头抄写。三分钟后,议员乙、丙、丁陆续举手——"我抄完了。"

议长甲数了数:连自己一共**四票**,过了半数。

> 【伏笔】议员戊没举手——他趴在桌上打瞌睡。议长甲看了一眼,没等他。

「咚!」议长甲敲了一下槌,「议案通过,记入校史,不可涂改。」

> 【反转揭晓】同学愣了:"可是还有人(议员戊)没抄啊?"

议长甲摇头:「校规写得很清楚——**只要过半数议员誊抄确认,议案就算通过**。这是为了防止一两个人缺席就导致整个议会停摆。没誊抄的人,事后补抄即可,但议案已经生效。」

> 【知识点可视化】"多数派确认即提交"= 过半数议员誊抄后议长敲槌,记入校史不可撤销。

「那……如果议长你自己突然病倒呢?」同学追问。

「那就重新选举。」议长甲摊手,「任何一位议员都可以宣布参选,过半数选票当选新议长。新议长上任后,会先检查大家的议事本,把缺的议案补齐——**但已经记入校史的,谁也不能涂改**。」

> 【约束可视】"leader 故障 → 重选" + "已提交不可撤销" = 议长病倒重选 + 校史不可涂改。

> (本段满足:角色化、场景化、对话化、拟人化、伏笔/反转,共 5 项 ≥ 3 项)

### 知识点校验

Raft 是分布式共识算法,通过 **leader 选举** 和 **日志复制** 实现多节点一致性:节点角色分 leader / follower / candidate,leader 由多数派选票当选(一个 term 内最多一个 leader);leader 将操作日志复制给所有 follower,当日志被**多数派(过半数)节点确认**后即被"提交"(commit),提交后的日志不可撤销(安全性保证);leader 故障时,剩余节点重新选举新 leader,新 leader 会补齐日志但不会推翻已提交的日志。多数派机制保证系统在少数节点宕机时仍可继续推进(可用性),同时保证已提交数据不丢(安全性)。

## 示例 4(可选):抗体免疫机制(医学)

### Input

> 抗体免疫:B 细胞识别抗原后产生特异性抗体,抗体与抗原结合并标记之,巨噬细胞清除标记物;同时部分 B 细胞分化为记忆细胞,下次同种抗原入侵时快速反应。

### 1. 理解

- **原文含义复述**:抗体免疫是适应性免疫的核心。当外来病原体(抗原)入侵,B 细胞识别其特征后,大量增殖并分泌抗体——抗体像"标记笔"一样特异性结合抗原,被标记的抗原随后被巨噬细胞吞噬清除。同时,一部分 B 细胞分化为记忆细胞长期存活,下次同样的抗原再来,记忆细胞能快速增殖产生抗体,实现"二次应答更快更强"。
- **核心难点**:
  1. "特异性"——抗体只认一种抗原,像锁与钥匙。
  2. "记忆"——为什么第二次得同一种病往往比第一次轻。
  3. 区分"B 细胞 / 抗体 / 巨噬细胞 / 记忆细胞"四个角色的分工。
- **歧义与假设**:无显著歧义。简化假设:不展开 T 细胞辅助、亲和成熟等细节,聚焦"B 识别 → 抗体标记 → 巨噬清除 → 记忆留存"主干。

### 2. 提炼

- **关键概念 / 变量**:
  - **抗原(antigen)**:外来病原体的特征分子,触发免疫应答。
  - **B 细胞**:识别抗原并产生抗体的免疫细胞。
  - **抗体(antibody)**:B 细胞分泌的蛋白,特异性结合抗原,起"标记"作用。
  - **巨噬细胞(macrophage)**:吞噬清除被抗体标记的抗原的细胞。
  - **记忆细胞(memory cell)**:部分 B 细胞分化而成,长期存活,二次应答时快速增殖。
  - **特异性(specificity)**:一种抗体只结合对应的一种抗原(锁与钥匙)。
  - **初次应答 / 二次应答**:首次入侵反应较慢较弱;再次入侵反应更快更强。
- **关系**:
  - 抗原入侵 → B 细胞识别 → B 细胞分泌抗体 + 分化为记忆细胞。
  - 抗体结合抗原(标记)→ 巨噬细胞清除被标记抗原。
  - 同种抗原再次入侵 → 记忆细胞快速增殖 → 大量抗体。
- **约束条件**:
  - 特异性约束:一种抗体只对应一种抗原(锁钥匹配)。
  - 记忆细胞寿命长但非无限。
  - 二次应答的前提:必须是**同种**抗原(否则记忆细胞不识别)。

### 3. 抽取

- **映射关系**:

  | 知识概念 | 故事元素 | 对应理由 |
  |---|---|---|
  | 抗原 | 试图混进城的外来通缉犯 | 外来入侵者,有可识别特征 |
  | B 细胞 | 城门口的"画影图形师" | 识别通缉犯特征并绘制通缉令 |
  | 抗体 | 通缉令(画着通缉犯画像) | 特异性标记通缉犯,贴在他身上 |
  | 特异性(锁钥匹配) | 通缉令只认一种长相,长得不像的不抓 | 一种抗体只结合一种抗原 |
  | 巨噬细胞 | 巡城捕快 | 见到贴着通缉令的人就抓走清除 |
  | 记忆细胞 | 留档的通缉令底稿(挂在城门陈列室) | 长期保存,下次同犯再来直接复用 |
  | 初次应答 | 第一次画通缉令,慢,要现画 | 首次识别需时间增殖产抗体 |
  | 二次应答 | 第二次同犯来,直接从陈列室取底稿大批复印 | 记忆细胞快速增殖产抗体 |
  | 约束:特异性 | 故事规则:"通缉令只认一种长相,抓错人无效" | 一种抗体只结合一种抗原 |
  | 约束:二次应答需同种抗原 | 故事规则:"只有长得和底稿一模一样的再来,才能直接复印" | 必须同种抗原才触发记忆应答 |

- **类比机制说明**:城门口画影图形师(B 细胞)识别外来通缉犯(抗原),绘制通缉令(抗体)贴在通缉犯身上,巡城捕快(巨噬细胞)见到贴通缉令的就抓走清除;同时画师把通缉令底稿留档挂在陈列室(记忆细胞),下次同一个通缉犯再来,直接取底稿大批复印(二次应答),反应快得多。

- **神似检查**:
  - 抗原入侵 ↔ 通缉犯混入 ✓
  - B 细胞识别 ↔ 画师识别并绘图 ✓
  - 抗体标记 ↔ 通缉令贴身 ✓
  - 巨噬清除 ↔ 捕快抓人 ✓
  - 记忆留存 ↔ 底稿留档陈列 ✓
  - 二次应答更快 ↔ 取底稿复印比现画快 ✓
  - 特异性 ↔ 通缉令只认一种长相 ✓
  - 机制完全同构,神似成立。

- **保真检查**:
  - 约束"特异性"→ "通缉令只认一种长相" ✓
  - 约束"二次应答需同种抗原"→ "底稿只对同犯有效" ✓
  - 全部可嵌入,保真通过。

### 4. 转换(标准档 · 二次元轻小说风)

> 边境小城"免疫町"的南城门,清晨。城门官 B 姬正打着哈欠值班。

「报告!」守城小兵跑来,「有个家伙混进商队想进城,形迹可疑!」

B 姬凑近一看:那人脸上有一道独特的疤,正是通缉令上画过的"疤面党"成员——这就是**抗原**,外来入侵者。

「我认得这张脸。」B 姬撸起袖子,从画具袋里掏出炭笔,飞快在纸上勾勒出那道疤的形状——这就是**抗体**,一张专门画着疤面党特征的通缉令。

> 【角色化 + 拟人化】B 姬 = B 细胞,绘制通缉令 = 分泌抗体。

「贴!」B 姬把通缉令啪地贴在那人背上。

那人还想挣扎,可通缉令像磁石一样牢牢吸住——因为这张令**只画了疤面党的疤**,贴别人身上根本贴不住。

> 【约束可视】"一种抗体只结合一种抗原" = 通缉令只认这一种疤,贴别人无效。

「捕快大哥!」B 姨喊。

巡城捕快"巨噬大叔"扛着大棒路过,一眼看见背着通缉令的人,二话不说扛走——**被标记的抗原被清除**。

> 【拟人化】巨噬细胞清除 = 捕快抓走贴通缉令的人。

「不过……」B 姬抹了把汗,看着地上那张皱巴巴的通缉令底稿,「第一次画真慢,我从头素描花了小半个时辰。」

她把底稿仔细收好,挂进城门旁的陈列室:「下次这家伙再来,我直接拿底稿去印,一刻钟能印一百张。」

> 【伏笔】B 姬把底稿留档 = 记忆细胞形成。

三个月后,疤面党果然又派人来。

B 姨连笔都没拿,直接冲进陈列室取下底稿:「老熟人!」一刻钟,一百张通缉令贴满进城通道。疤面党的人还没反应过来,就被捕快大叔一锅端。

> 【反转揭晓】"二次应答比初次快且强"的视觉化:第一次现画慢、产量少;第二次直接复印,快且量大。

「这就叫记忆。」B 姬拍了拍陈列室的墙,「**只要同一种通缉犯再来,底稿还在,我们就能比第一次快十倍地响应。**」

> 【约束可视】"二次应答需同种抗原" = 底稿只对同一种疤有效,换个长相的通缉犯还得重新画。

> (本段满足:角色化、场景化、对话化、拟人化、伏笔/反转,共 5 项 ≥ 3 项)

### 知识点校验

抗体免疫是适应性免疫的核心机制:抗原入侵后,B 细胞特异性识别抗原并分泌抗体,抗体与抗原特异性结合(一种抗体只结合对应的一种抗原,具锁钥特异性)起标记作用,巨噬细胞随后吞噬清除被标记的抗原;同时部分 B 细胞分化为记忆细胞长期存活。当**同种抗原**再次入侵时,记忆细胞快速增殖并大量分泌抗体,使二次应答比初次应答更快更强,这是疫苗接种与再次感染症状较轻的免疫学基础。
