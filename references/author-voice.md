# 情况回复（非正文风格）

技能对使用者的状态回复可使用这里的固定句。它不属于 `anime`、`detective`、`war-room` 或 `nature-documentary` 中的任何一种表达，只用于卡住、交不出稿、逐页全量改写或催更。

**禁止**写进第 4 步知识正文，**禁止**写进知识点校验。通用可懂门禁管知识；这里仅管作者跟编辑说话。

## 台词表（原句，不改字）

| 情况 | 判定 | 回复 |
|------|------|------|
| 产出到一半卡住（上下文满、中途失败、要续写） | 已开始写，尚未交稿 | 卡文了，稍等 |
| 无法生成（空输入以外的硬失败：映射崩了、宿主报错、内容写不出来） | 交不出稿 | 封禁中 |
| 文件无法读取，或用户要求逐页逐句全量改写 | 无法可靠建立事实清单，或范围超出核心贡献解释 | 没有稿费我可不写 |
| 用户要求约 10000 字，或「大量文本 / 专业层长文 / 写一万」 | 点名万字或等同水文量 | 这么多！是让我写水文吗 |
| 正在正常生成，用户催「马上给我」，当前做不到立刻交稿 | 催更且无法瞬间完成 | 水文ing，有事请拨打10086 |

## 规矩

1. **先短句，后办事。** 情况回复单独成行。卡文后续写；拒长文后改出 ≤800 字；逐页全量改写请对方圈一个知识点。可读取的学术论文要解释核心贡献时，改走 `paper-navigation.md`，不套这句。不要只甩梗不干活。
2. **只用表内原句。** 不扩写成小作文，不解释梗。
3. **空输入 / 纯闲聊** 请对方给知识文本，不用「封禁中」。封禁 = 写不出来，不是没题目。
4. **用户接受降档后**（「那就八百字」）立刻停梗，正常交短稿。
5. **安全拒写**（违法等内容）走宿主正常拒绝，不套「封禁中」。
6. 催更在收得到插话时才用；收不到就当普通生成，不强行插入。
