# 通用可懂门禁

第 5 步必读。白居易写完诗念给不识字的人听：解，则录；不解，则易。本技能用同一环：写完先自测，过关再交稿。

本文件管「转换出来的知识能不能听懂」。它对 `anime`、`detective`、`war-room`、`nature-documentary` 与 `neutral` 完全相同；情况回复不管这里，见 `author-voice.md`。

## 过关标准

假装把正文念给「从没学过这个领域的人」听。过关当且仅当：

1. 对方能用一句大白话说出「这东西在干什么」。
2. 第一次出现的必要术语，都用表达中的动作、场景或直接例子解释过。
3. 未解释的专业词尽量为 0。
4. 约束（分母不能为零、多数派、终止条件等）要作为可见规则发生作用，而不是只写在括号里。

把「外行复述」那一句话写进折叠分析区，便于反向修正。

## 改稿步骤

1. 列出会让对方皱眉的词和句子。
2. 每个皱眉点：改成动作，或删掉。禁止用术语解释术语。
3. 再念一遍。还有皱眉就继续改。
4. 过关后再写知识点校验（严谨复述，1–3 句，不进故事腔）。

## 可检查规则

1. 一句一事；解释机制的句子要短，能停顿。
2. 先说它在干什么（动词），再说它叫什么（术语）。
3. 必须留下的术语，第一次出现时用故事动作解释。
4. 一个概念只由一个表达元素承担（粒度匹配，见 `mapping-principles.md`）。
5. 约束变成可见规则。
6. 读完应能回答三问：它在干什么？它怕什么（约束）？看走眼会怎样？

## 失败样例

| 失败 | 为什么过不了 | 怎么改 |
|------|--------------|--------|
| 「后验等于似然乘先验除以边缘」 | 术语解释术语 | 先演「改写怀疑度」，再给这三个名字 |
| 全文堆满角色口癖、侦探黑话、岗位缩写或景物名 | 风格词变成新的专业词 | 降低风格浓度或改为中性，味道让路 |
| 800 字里没出现约束 | 边界被省略 | 让规则实际限制一步（没有脚印就不能改怀疑） |
| 为吸睛让凶手招供 | 机制错配 | 反转只能等于知识点本身的洞察 |

门禁失败时降低风格浓度、换意象或改为中性说明，不要加更长的旁白。
