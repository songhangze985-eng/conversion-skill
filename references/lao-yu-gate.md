# 通用可懂门禁（老妪能解）

第 5 步必读。白居易写完诗会念给不识字的老妇人听：听得懂才录下，听不懂就改到懂为止。无论选用哪种表达风格，交稿前都必须过这道门禁。

## 什么样的文章才算真正过关？

想象你把写好的正文念给一位**聪明但完全没学过该专业的朋友**听。过关必须同时满足四条：

1. **一口气读下来不卡壳**：句子有自然的轻重缓急，没有机器翻译腔、没有强行拼凑的括号批注、也没有像报菜名一样的术语堆砌。
2. **先见其事，后闻其名**：任何必要保留的专业术语，在第一次亮相前，读者已经在场景里看懂了「它到底在干什么」。
3. **限制条件「活」在场景里**：分母不能为零、过半数才生效、只剩一个就停止——这些关键约束必须在过程里真实拦住一次动作，让读者直观看到「如果不守这条规矩会出什么乱子」。
4. **合上文章能复述**：朋友听完后，能用自己的一句大白话说出：「哦，它其实就是先……再……直到……为止。」

## 三步改稿法

1. **揪出「皱眉点」**：通读正文，标出所有让人想停下来问「这词啥意思？」「这句话怎么这么绕？」「为什么突然蹦出这个人名？」的地方。
2. **化词为事**：
   - 把抽象名词拆成具体动作（如把「先验概率与似然度相乘」化为「先看原本有几分把握，再看新线索有多支持这个猜测」）。
   - 删掉所有只为耍帅而存在的黑话、口癖或生搬硬套的设定词。
3. **补齐独立校验段**：正文打磨顺畅后，在内部完整稿的「知识点校验」区，用 1–3 句平实、准确的专业白话复述核心机制，确保通俗化没有牺牲严谨性。

## 常见翻车与改法对照

| 翻车写法 | 为什么生硬 / 过不了门禁 | 自然改法 |
|---|---|---|
| 「皮沃特老师对小快说：我是本轮的基准值！」 | 把术语硬译成假人名，角色像在背教科书 | 换成真实生活身份：「体测排队时，老师随手点名阿杰站出来当标杆。」 |
| 「后验等于似然乘先验除以边缘。」 | 用术语解释术语，外行读完依然一头雾水 | 先把「原有把握 + 新线索分量 + 线索本身常不常见」的三步账算清楚，最后再点出这三个名字 |
| 正文里突然插一句：「（注：这里是清单原因，那是环境暗示）」 | 把内部审稿批注写进了文章正文，彻底打断阅读感 | 把原因自然融进上下文处境里，内部核对留给 `<details>` 映射表 |
| 为了让侦探故事刺激，写「凶手突然心理崩溃招供了」 | 剧情反转脱离了原机制，读者记住了热闹却记错了原理 | 反转必须等于机制本身的洞察（比如「原来这项罕见指标在健康人里也会成批出现，所以不能凭它定罪」） |
