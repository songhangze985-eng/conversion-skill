# 事实可追溯

第 2 步必读。目标是让后面的比喻都能回到依据，而不是先写故事再倒推事实。

## 四类条目

把清单里的每一条标成下面四类之一。一类一条，不要混写。

| 类型 | 可以进入正文吗 | 可以写入知识点校验吗 |
|---|---|---|
| 原文事实 | 可以 | 必须保留 |
| 必要推导 | 可以，且要看得出是推出来的 | 可以，但必须写清由哪条事实推出 |
| 理解用类比 | 可以，作为皮肤 | 不可以冒充原文结论 |
| 尚未确认 | 只能作为缺口说明 | 不可以 |

原文事实来自用户粘贴的文本、公式、可读取论文中的主张，或用户明确给出的约束。论文条目还要有页码或章节锚点，规则见 `paper-navigation.md`。

必要推导只覆盖「不补这一步就无法讲清机制」的内容，例如从「多数派确认后提交」推出「一个人反对不能单独否决已提交记录」。推导不能引入原文没有的数据、因果或结论。

理解用类比是为了降低门槛。它帮助记忆，不增加知识。写进映射表时必须带适用边界。

尚未确认包括读不到的页、互相冲突的抽取结果、以及资料不足以支持的机制。遇到这类条目就停，向用户要页码、摘录或更小范围；不要编造来源。

## 最小写法

折叠分析里用短列表即可：

```markdown
- 原文事实：选一个 pivot；比它小的放一边，大的放另一边；再对两边重复。
- 必要推导：pivot 分区完成后位置已定，所以它不再进入下一轮比较。
- 理解用类比：达标线把人分成两拨。这不是运动会规则本身。
- 尚未确认：原文没有说明是否原地排序，因此不把它写成必经步骤。
```

## 禁止

- 把类比里的角色动机写成原文机制。
- 为了故事完整而补实验数字、论文结论或「作者一定是这个意思」。
- 资料读不清时仍输出带页码的假锚点。
- 因为清单很长，就认为解释已经正确。清单只是后续映射和校验的输入。
