# 播客对谈写作工作流

在事实清单与场景映射完成后，按以下四拍节奏写出自然、有来有回的双人播客对谈（默认正文 ≤ 800 字）。

## 1. 抛直觉靶子（开场切入）

不写「欢迎收听某某播客」。由主持人用一句话直接抛出**普通人最自然的直觉或困惑**：
- 例：「我一直有个疑问，两个人打电话确认听得见，一问一答两次不就够了吗？为什么 TCP 非要握三次手？」
- 一上来就把核心矛盾摆在桌面上。

## 2. 顺着直觉拆招（推进机制）

嘉宾不要上来就背定义，而是**先接住主持人的话头，带入一个生活场景**：
- 每一轮对话围绕一个核心推进点展开。嘉宾用具体场景讲清「先发生了什么、紧接着怎么处理」。
- 主持人在关键节点自然插话追问：「等等，那如果……呢？」把复杂的机制拆成两三个轻快的回合，避免嘉宾一个人长篇大论独白。

## 3. 追问边界与刹车条件（点破约束）

当主流程讲通后，由主持人替听众问出最关键的边界或终止问题：
- 「照这么一直分下去，什么时候是个头？」或「万一中间这一步包裹丢了，两边岂不是永远对不上账？」
- 嘉宾借这个追问，把原机制的**核心约束、容错规则或终止条件**彻底讲透。

## 4. 一句话拎出主干（收束复盘）

对谈结尾，由主持人用一句大白话做「听众复盘」：「所以我可以这么理解——它其实就是靠……来保证……对吧？」嘉宾简短确认或补全最后一块拼图，干净收尾。
