# 苏格拉底微步自适应教学（Adaptive Socratic Micro-stepping）

> **重要说明（性能边界标注）**：本「循序启发 / 苏格拉底微步教学」模式的具体输出效果与多轮追问质量，**由宿主 Agent（底层大模型）本身的推理与上下文把控性能决定，而不是由本 Skill 决定**；本 Skill 仅提供交互节奏与步进约束规范。

默认情况下，`conversion-skill` 采用「五步转化后一次性交付折叠正文」的完整文章模式。但当用户明确提出**「一步步带我推」「边问边讲」「先别直接给答案，考考我的直觉」**，或者面对极易产生直觉误区（如贝叶斯基础率谬误、CAP 三选二误解、TCP 两次握手陷阱）的机制时，切换至本**微步自适应教学工作流**。

## 为什么需要微步闭环？

单向长文广播最大的风险是：读者在第一步就产生了错误脑补，却带着这个错误印象读完了全文。微步教学通过**「探测直觉 → 暴露冲突 → 微步推演 → 边界迁移」**的四步闭环，把单向阅读变成双向对齐。

## 四步交互规程

### 第 1 步：直觉探测与痛点设问（Probe）

不要一上来就抛术语或贴完整长文。先用 **100–150 字** 搭建生活场景的核心冲突，并抛出一个**直觉预测问题**，停下来等待用户回答：

- **贝叶斯示例**：「雨夜命案现场留下一双限量版军靴脚印，全城只有千分之一的人穿过这款靴子。嫌疑人阿杰家里正好搜出一双，侦探当场断定阿杰有 99% 的把握是真凶。你觉得侦探漏算了哪一笔账？」
- **TCP 握手示例**：「甲给乙发信问『听得见吗』，乙回信说『听得见，你呢』。如果这时候乙就直接打开库房等甲送货，万一刚才甲发出的是一封在路上滞留了半天的旧废信，会发生什么乱子？」

### 第 2 步：顺着用户的回答做微步推进（Micro-step）

根据用户的回复分流，每次只推进**一个因果环节**（单轮正文控制在 **150–250 字** 以内，保持 1–2 个饱满自然段，严禁退化为一行一句或列表堆砌）：

1. **若用户直觉踩中卡点**：顺着他的话点出专业术语（如「你抓到的这笔『路人撞款账』，在概率上就叫**边缘概率**」），并推演下一步动作。
2. **若用户落入直觉陷阱**：不要生硬说「你错了」，而是顺着他的假设往下推一步，让他亲眼看到场景里发生荒谬后果（如「如果按这个规矩直接敲槌，隔壁还在打瞌睡的三个席位醒来就会各认各的账本，校史当场分裂」），再引出机制里的硬性限制条件。

### 第 3 步：诚实揭晓类比边界（Boundary Reveal）

在核心机制对齐后，主动用一两句大白话挑明当前生活场景在哪一步会「穿帮」（对应内部四列映射表的「适用边界」列），并附上一道轻量级的**跨场景迁移追问**，确认用户掌握的是底层机制而非故事表面。

### 第 4 步：按需汇总完整复盘稿（Consolidation）

当微步互动结束、用户表示「懂了，帮我整理一份完整笔记」时，再按标准五步法生成包含幕后 `<details>` 四列映射表、完整叙事正文与知识点校验的定稿，并通过 `check-output` 门禁验收。
