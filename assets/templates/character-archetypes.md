# 常用二次元角色原型参考

转换skill 在"角色化"风格要素中,可参考以下角色原型来实体化抽象概念。选择时注意角色性格与概念特性的匹配(神似优先)。

## 原型列表

### 1. 少女侦探
- **性格特征**:冷静、逻辑强、善于推理,常在线索汇聚时豁然开朗。
- **适合映射的概念类型**:概率/推理/更新类概念(如贝叶斯推断、假设检验、卡尔曼滤波)。
- **示例**:"贝叶斯酱"——每收到新证据就更新自己的嫌疑名单。

### 2. 热血运动少年
- **性格特征**:不服输、拼尽全力、层层挑战,遇强愈强。
- **适合映射的概念类型**:递归/排序/竞争类算法(如快速排序、归并排序、动态规划)。
- **示例**:"快排君"——把球场上分而治之的战术用到了数组上。

### 3. 傲娇大小姐
- **性格特征**:口是心非、外冷内热,只有满足特定条件才展露真心。
- **适合映射的概念类型**:有门槛/条件触发型机制(如互斥锁、条件变量、事件驱动)。
- **示例**:"锁小姐"——只有拿到钥匙才肯开口,否则一直喊"你先出去"。

### 4. 天然呆学妹
- **性格特征**:迷糊但直觉准,常凭感觉命中正确答案。
- **适合映射的概念类型**:启发式/概率近似概念(如蒙特卡洛方法、模拟退火、贪心近似)。
- **示例**:"蒙特卡洛学妹"——闭眼撒豆子,居然算出了圆周率。

### 5. 冷酷执事
- **性格特征**:严谨、守规则、一丝不苟,违反规矩的事绝不做。
- **适合映射的概念类型**:约束/校验/类型系统(如类型检查器、schema 校验、不变量维护)。
- **示例**:"类型执事"——客人进门先验身份,类型不符一律拒之门外。

### 6. 中二魔王
- **性格特征**:夸张、戏剧化、专有名词多,喜欢宣读华丽咒文。
- **适合映射的概念类型(重度档)**:共识协议/加密算法等需要戏剧张力的概念(如 Paxos、Raft、RSA、零知识证明)。
- **示例**:"Paxos 魔王"——在三个分裂的人格之间达成共识才能发动禁咒。

### 7. 温柔教师
- **性格特征**:耐心、循循善诱,善于用生活类比讲解。
- **适合映射的概念类型(轻度档)**:基础概念入门讲解(如变量、循环、函数、栈与队列)。
- **示例**:"栈老师"——用一摞盘子解释后进先出。

### 8. 机甲少女
- **性格特征**:精密、模块化、协同作战,各部件分工明确。
- **适合映射的概念类型**:分布式系统/微服务架构(如负载均衡、服务发现、一致性哈希)。
- **示例**:"哈希机甲"——通过环状编队分配任务,谁离目标近谁上。

## 选择原则

- **神似优先**:角色性格要与概念机制同构。例如"条件触发"概念配傲娇大小姐(外冷内热、条件才触发),而非热血少年。
- **避免强行映射**:如果概念与现有原型不匹配,可原创角色,但需在"意象映射"节说明原创角色的设定理由。
- **风格档位联动**:
  - 轻度档 → 温柔教师 / 冷静学者型
  - 标准档 → 少女侦探 / 天然呆学妹 / 冷酷执事 / 机甲少女
  - 重度档 → 中二魔王 / 热血少年 / 傲娇大小姐

## 命名建议

采用"概念名 + 昵称后缀"的形式,便于读者快速对应:

- 酱:亲切俏皮,如"贝叶斯酱""梯度酱"
- 同学:中性学生感,如"快排同学""动态规划同学"
- 小姐:有距离感/条件型,如"锁小姐""条件变量小姐"
- 君:略带敬意,如"归并君""二分君"

也可组合使用,如"贝叶斯酱"用于标准档,"贝叶斯大人"用于重度档以提升戏剧感。

## 随机生成流程

当触发随机生成模式时,按以下步骤执行:

1. **领域识别**:从第 2 步提炼的知识点中识别领域(概率/算法/系统/约束/分布式/基础/架构等)。
2. **原型筛选**:对照上文"原型列表"中每个原型的"适合映射的概念类型",保留匹配项。
3. **随机抽取**:从匹配原型中随机取 1-2 个(简约模式取 1 个,适中回退取 1-2 个)。
4. **命名生成**:按"命名建议"规则,结合概念名生成角色名(如"贝叶斯酱")。
5. **字段补全**:补全性别、能力素养、专业领域;基础数值可留空。
6. **无匹配兜底**:若所有原型均不匹配,原创角色并在第 3 步说明理由。

## 自定义角色字段模板

用户触发自定义模式时,可按以下模板提供角色信息(复制填充):

```
角色数量:2
角色1:
  姓名:贝叶斯酱
  性别:女
  能力素养:高级(9/10)
  专业领域:概率推理
  基础数值:身高158cm,体重45kg(可选)
角色2:
  姓名:频率君
  性别:男
  能力素养:中级(6/10)
  专业领域:统计采样
  基础数值:(可不填)
```

必填字段(角色数量/姓名/性别/能力素养/专业领域)缺失时,skill 回退到随机生成模式并提示用户。基础数值为可选字段,不影响故事质量与知识保真。
