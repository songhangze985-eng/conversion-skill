# 二次元角色原型

仅皮肤读取。神似优先：性格要能解释机制。对不上就原创，并在映射表说明理由。

## 原型

| 原型 | 性格 | 适合的概念 |
|------|------|------------|
| 少女侦探 | 冷静、会改判断 | 概率、推理、更新 |
| 热血运动少年 | 层层比下去 | 递归、排序、分治 |
| 傲娇大小姐 | 条件才开口 | 锁、门槛、事件触发 |
| 天然呆学妹 | 乱试也能逼近 | 启发式、采样 |
| 冷酷执事 | 规矩不能破 | 类型、校验、约束 |
| 中二魔王 | 戏剧化（仅重度） | 共识、密码（用户点名重度时） |
| 温柔教师 | 口语类比（轻度） | 入门定义 |
| 机甲少女 | 部件分工 | 分布式、负载 |

轻度偏教师；标准偏侦探 / 执事 / 机甲；重度才上魔王。命名用短名：概念 + 酱 / 君 / 老师。不要为角色编身高体重。

## 随机（默认）

1. 从第 2 步的领域筛原型。
2. 取 1 个（默认短篇）或 2 个（用户要多角色）。
3. 用概念名生成称呼。
4. 对不上就原创。

用户主动给了角色名，就用用户的名字；没给就不要追问五字段。
